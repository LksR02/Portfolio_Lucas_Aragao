# Portfólio de Lucas Aragão

Site profissional sobre Ciência de Dados aplicada ao setor elétrico.

## Publicação

O GitHub Actions publica automaticamente o conteúdo de `site/` no GitHub Pages após cada atualização da branch `main`. O workflow também pode ser iniciado manualmente pela aba Actions.

## Edição

- `site/index.html`: textos, projetos e links de contato.
- `site/styles.css`: cores, tipografia, espaçamento e adaptação para celular.
- `site/script.js`: menu móvel.
- `site/favicon.svg`: ícone do site.

Para publicar alterações, atualize os arquivos em `site/` e envie as mudanças para `main`.
